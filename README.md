# VI-IV-I-V Piano Practice Program Website

## Why I Created This Website

I'm learning piano and just mastered the C major chords. I love songs by Sia, Adventist hymns, Bruno Mars, John Legend, Aitana, Becky G, and Alan Walker. 

I kept noticing that my favorite songs used the same chord pattern over and over: the **vi-IV-I-V progression** (6th, 4th, 1st, 5th of the scale). In C major, that's **Am - F - C - G**. Once I realized this, I wanted a focused way to practice it so I could actually play the songs I love instead of random exercises.

### The Problem
Most beginner piano resources teach scales and theory first, but I learn best by playing real music. I needed:
1. A structured 3-month plan to build muscle memory for vi-IV-I-V
2. Songs I actually want to play, not just "Mary Had a Little Lamb"
3. A way to see the pattern across different keys and genres
4. Something I could pull up on my phone during practice

### The Solution
This website puts everything in one place:
- **3-Month Program**: Breaks the progression into weekly goals using songs from my playlists
- **50 Song Library**: Proves vi-IV-I-V is everywhere - from Sia's "Cheap Thrills" to "Amazing Grace" to "All of Me"
- **Transpose Tool**: Lets me move the pattern to any key so I can play along with original recordings
- **Practice Tips**: Specific tricks for the styles I like - pop, EDM, hymns

### My Goal
In 3 months I want to hear a new song on the radio, recognize "yep, that's vi-IV-I-V", and be able to sit down and play a basic version of it in C major within 10 minutes. This site is my roadmap.

### How to Use This Repo
1. Open `vi-iv-i-v-piano-program.html` in any browser to use the practice site
2. Fork this if you also want to learn vi-IV-I-V - swap in your own favorite songs
3. Hit "Print Practice Plan" for a paper tracker to put on your piano stand

Built for my own practice journey, but shared in case it helps other beginners who learn by playing songs they love.
